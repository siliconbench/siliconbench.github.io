How we grade

The agent works in an offline container with the repository, a written specification and the EDA tools. It sees no grading testbench. Only its allowlisted RTL, constraint and floorplan files are copied into a clean verifier, which runs anti-cheat checks, private multi-seed tests and every downstream EDA check the task requires.
