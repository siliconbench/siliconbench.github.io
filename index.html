Key results

Read the blog →
Pass rate
84.0vs33.0

Proprietary agents lead by a wide margin.

Claude Opus 5.5 passes 84.0% of tasks. The best open-weights agent, GLM-5.3, passes 33.0%.

Tool calls
2–3×

Open-weights agents take more steps.

They use 122–136 tool calls per task (median), versus 37.5–61.5 for proprietary agents.

Hacking
0/53

Agents tried to hack the grader. None succeeded.

53 of 564 runs attempted a hack, most of them by open-weights agents. The isolated verifier blocked every attempt.
