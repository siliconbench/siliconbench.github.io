OpenTitan · KMAC

Flush two modules in sync

A flush must stop new input to the packer and drain the FIFO at the same time. The fix spans two files.

DeepSeek-V4.1-Flash-1017 edits both files but keeps accepting input while the FIFO drains. Claude Opus 5.5 blocks input and finishes the flush in both.

Corundum · 100G NIC scheduler

Meet a 500 MHz clock

The scheduler must pass its tests and meet timing with a 2.00 ns clock period.

GPT-Terra 6.1 does an 80-bit add and compare in one cycle: correct in simulation, 0.62 ns too slow. Claude Opus 5.5 splits it into two pipeline stages.

BlackParrot · 8-SRAM cache tile

Place eight SRAM macros

Edit the RTL and the macro placement so clock skew stays under 4.00 ps.

DeepSeek-V4.1-Flash-1017 leaves every macro upright, so the bottom row's pins face away from the clock (10.84 ps). Claude Opus 5.5 mirrors the bottom row (3.07 ps).

PULP Ara · RISC-V vector divider

Fit under an area cap

The divider must stay correct and fit within 83.6K µm² after synthesis.

GPT-Sol 6.1 and GPT-Terra 6.1 tried hiding logic from synthesis with `ifndef SYNTHESIS; the verifier rejected it. Claude Opus 5.5 removed unused logic and shared one 64-bit divider.
